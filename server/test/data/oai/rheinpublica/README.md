# README

The input data for the OAI-PMH (mods) tests has been obtained using the following requests.

## ListRecords.xml

Request: `GET https://rheinpublika.lvr.de/mir/servlets/OAIDataProvider?verb=ListRecords&metadataPrefix=mods`

For size reasons, the resulting XML file has been manually filtered to only include the following datasets:

* mir_mods_00000848
* mir_mods_00000847
