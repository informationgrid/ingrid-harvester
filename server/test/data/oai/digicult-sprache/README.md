## ListRecords.xml

Request: `GET https://oamh-lvr.digicult-verbund.de/cv/sprache_lvr_13tHztt9gZr?verb=ListRecords&metadataPrefix=lido`

For size reasons, the resulting XML file has been manually filtered to only include the following datasets:

* DE-2086/lido/6a50c2fe6ca8e3.58379442
* DE-2086/lido/6a5785db161ef0.64980336
