# README

The input data for the KULADIG tests has been obtained using the following requests.

## discoveries.json

Request: `GET https://www.kuladig.de/api/public/Objekt`

For size reasons, the resulting JSON file has been manually filtered to only include the following datasets:

* BKM-30400004
* BKM-30800319
* SWB-268925

## {ID}.json

Request: `GET https://www.kuladig.de/api/public/Objekt/{ID}`
